# Kalnet-AI-5 Email Automation Pipeline

Project Title: EMAIL OUTREACH AUTOMATION PIPELINE 

PROJECT OVERVIEW:
Kalnet AI-5 is an AI-powered Email Automation that manages and tracks outreach campaigns to leads through an intelligent 3-email sequence system.
The system automatically sends follow-up emails at scheduled intervals, tracks replies, identifies unsubscribe requests, and provides real-time analytics on email performance.

LIVE DEPLOYMENT APPLICATION: https://kalnet-ai-5.onrender.com

Functions and Services provided:
->Lead management database
->Reply tracking & management
->Analytics & performance reports
->Email campaign settings
->Automated pipeline execution
